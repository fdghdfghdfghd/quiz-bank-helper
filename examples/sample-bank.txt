练习题库助手 · 题库格式示例
============================

下面这份文件展示了脚本能识别的几种常见写法。
把你自己题库按这个形状整理，导入成功率最高。


---------------- 一、单选题 ----------------

1. 下列哪个是 HTTP 状态码？
A. 200
B. 404
C. 302
D. 500
答案：B

2. 中国的首都是？
A. 上海
B. 北京
C. 广州
D. 深圳
答案：B

3、题号用顿号也可以
A、选项一
B、选项二
答案：A

(4) 括号编号也认
A) 选项一
B) 选项二
答案：B


---------------- 二、多选题 ----------------

5. 下列哪些属于前端技术？（多选）
A. HTML
B. CSS
C. MySQL
D. JavaScript
答案：ABD

6. 下列哪些是浏览器？（字母之间带逗号也认）
A. Chrome
B. Nginx
C. Firefox
D. Redis
答案：A,C


---------------- 三、判断题 ----------------

7. 1 + 1 = 2
答案：正确

8. HTTP 是无状态协议
答案：错误


---------------- 四、填空题 ----------------

9. 计算机网络中，IP 地址的作用是______。
答案：标识网络中主机的地址

10. 光在真空中的速度约为______米每秒。
正确答案：3×10^8


---------------- 五、用「题目：」开头（无编号） ----------------

题目：以下哪一项不是编程语言？
A. Python
B. Java
C. HTML
D. Rust
答案：C


============================
格式要点（务必对照）
============================

1. 每道题以「题号 + 分隔符」开头：
   1.   /   1、   /   (1)   /   第1题
2. 选项以 A~D 开头，字母后面必须有分隔符：
   .   、   :   )   都可以；只用空格不行。
3. 答案行以「答案 / 答 / 正确答案 / 标准答案」开头，
   后面可以跟「：」「:」「、」或直接写内容。
4. 多选题写字母组合：AB / A,B / A、B 都行。
5. 判断题、填空题直接把答案写完整。
6. 题干和选项之间不要有空行也可以，但**每道题之间建议空一行**，
   便于人眼检查，脚本也能正常切分。
